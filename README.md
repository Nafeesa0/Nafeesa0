### [FestiCast](https://github.com/Nafeesa0/festicast)
*Decision-aware and festival-aware demand forecasting for Indian SMEs.*

Upload a sales CSV, get forecasts and see which model performs best. Festival-aware features are next.

- **Frontend:** React, Recharts
- **Backend:** Node.js (Express)
- **ML service:** Python, FastAPI, with baseline models (naive, seasonal naive, moving average) compared by backtest MAE
