## 🚧 Currently Building

### [FestiCast](https://github.com/Nafeesa0/festicast)
> Decision-aware and festival-aware demand forecasting for Indian SMEs.

A full-stack app where you **upload a sales CSV, get forecasts, and see which model performs best** on your own data.

| Layer | Stack |
|---|---|
| Frontend | React, Recharts (interactive charts) |
| Backend | Node.js (Express) REST API |
| ML service | Python, FastAPI |
| Models | Naive, seasonal naive, moving average, compared by backtest MAE |

**Roadmap:** festival-aware features · stock-risk alerts · anomaly detection · AI recommendations
